# Frozen holdout design

Select the earliest twelve correction notices in calendar year 2023 for the eLife journal (ISSN 2050-084X). Use the public Crossref journal works registration, correction relation or correction title, ordered by publisher date then notice DOI, deduplicated by DOI. If the journal registration has no usable way to enumerate, use the chronological list of all 2023 correction notices in the publisher's JATS repository instead and document the change before reading notices. Retain every selected notice even when it changes figures, affiliations or contributions only. A repository accessible via a Git host or an archival endpoint may supply historical full text. Data retrieval order and Git arrival time are distinct from publisher effective chronology.

Question: given a work and the publication cut, which ordered author byline names did the publisher credit before and after the correction? Include collaborations, retain literal normalized name components in order, and exclude affiliations, e-mails, prose acknowledgements and affiliation-only revisions. Count an explicit added/removed/reordered author, or changed printed name as changed credit; a correction author's list is not evidence of the original byline. Unknown when original source text or prior edition is unavailable. Do not infer that unchanged credit is established by absence of the word 'author'. Split notice-reported evidence (explicit change, explicitly another correction, indeterminate) from verified edition comparisons. Do not infer the identity of people behind similar names.

Compare a mutable-current-state baseline (substitute the later publisher byline for the early one) against version-aware retrieval (emit retained earlier byline only if available, with citations). Compare them only where independent version pairs verify the reference. Report notices selected and reviewed, distinct works, missing titles/links, independent version pairs and missing pairs, changed credits/assessable; report coverage and actual historical errors for each arm. No population claims at n=12. No automatic identity linking. Preserve licenses, source locations, file hashes, byline fingerprints and aggregate results; do not redistribute publisher text or full bylines.
