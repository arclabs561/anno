# Experiment records

Start with the study closest to the decision you are making. Each study names what it scores. A coreference link, an exact mention, and a directed relation have different denominators. For a comparison across backends, start with [where predictions failed](backend-residuals.md).

## Decisions for Anno

- **Reject the 0.40 CrossRE gate for automatic extraction.** It added 436 exact relations and 3,107 unmatched predictions across the official test release. Micro F1 fell from 29.50% to 28.75%. Keep 0.50 for this model and study configuration. The separate 0.55 CLI check covers the original 96 development and 192 test sentences. [Threshold and fixed-budget evidence](crossre-predicate-ranking.md)
- **Use endpoint-weighted confidence for the tested half-size CrossRE review queue.** On 1,989 previously unused development texts, it recovered 139 exact relations in 825 reviews. Predicate confidence recovered 123. The paired 95% interval for the gain was +5 to +26. On the previously examined official test release, the same rule recovered 173 against 131 in 1,011 reviews. [Frozen rule, independent confirmation and official test results](crossre-predicate-ranking.md)
- **Reject the fourth NuNER prompt as a WikiGold MISC repair.** It fixed two of the 263 exact-boundary type errors it was supposed to address. Across labels it displaced 31 correct mentions. On WNUT test it gained five mapped exact mentions and lost seven. [Prompt ablation and scored inventories](wikigold-nuner-routing.md#does-a-fourth-prompt-recover-misc)
- **Reject 0.025 as the default supplied-span pronoun margin.** On GAP validation it lost 14 correct links to avoid five wrong ones. It retained 23 of 37 previously correct links against a declared target of 80%. [Selection and held-out results](native-gap-link-retention.md)
- **Do not sign off a nested-annotation review from flat HTML alone.** On GENIA the exporter hid 5,031 of 55,740 supplied mentions. A span-preserving export shows reviewers the annotations the highlight suppressed. [Exact spans and exporter replay](../EXTRACTION_WORKFLOWS.md#review-overlapping-highlights)

For the next CrossRE change, prioritize predicate scoring. Even a perfect selector in the existing one-per-sentence queue could recover only 433 of the 5,404 stock misses on the additional holdout. On WNUT, start with mention detection for lowercase names. Of 216 unfamiliar mentions starting with a lowercase letter, 215 had no overlapping heuristic prediction. Test whether a new recognizer recovers those mentions and count the extra unmatched suggestions it sends to review. [CrossRE candidate ceiling](crossre-predicate-ranking.md) · [WNUT failure counts and type mapping](../DOMAIN_QA.md#compare-native-anno-on-unfamiliar-names)

## Record a trial

Put the question, compared arms, and replay command alongside the relevant study. Record the revision and input pins, cohort selection, observed backend and language where available, and the unit being scored. Give the paired counts for what improved and what regressed, the decision they support, and any arm that could not run. A result that preserves the current default is worth recording.

Link the note to a compact result file where sharing is permitted. Source text, per-document predictions and debug logs can expose the original material. Keep those with the authorized inputs and record how a reviewer can regenerate them. Project-authored regression fixtures and third-party materials with redistribution rights follow the [fixture and source policy](../QA.md#decide-what-to-keep).

Use `anno viz errors` to see which labels and spans an evaluation got wrong. Use `anno viz paired` to compare a named baseline and candidate on the same inputs. The WikiGold, GAP and CrossRE studies report exact matches gained and lost, total suggestions and measured costs. `anno viz tradeoff` shows a sweep over several settings at a chosen review or unmatched-prediction budget. For an extraction without gold annotations, `anno viz overlap` measures how often signals share characters.
