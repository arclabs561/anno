# Coreference corpus sources and reuse

The seven adapters read caller-supplied, pinned source data. The publishers supplied the underlying annotations or template answers. Anno constructs windows, selects candidate mentions, converts offsets and derives decisions. No one manually adjudicated the resulting Anno pairs in this pipeline. Cite both the upstream source and the transformation when reporting results. The manifest records each input, release, terms, attribution and available checksums. ## Where to run and keep a replay

- **Local evaluation.** Acquire the pinned input from the publisher or use an existing authorized copy. Give the adapter its local file or directory. The generic Anno loader uses `$ANNO_CACHE_DIR/datasets` or the platform cache. Specialized adapters have their own input layouts. Use scratch space for decoded text, model feeds and reviewer windows on a host covered for the evaluation. [Loader and cache behavior](../S3_CACHE_CI.md)
- **Repository and CI.** Store scripts, publisher references, hashes, independently authored fixtures and aggregate results appropriate for publication. Source-derived windows, copied template text, predictions that quote passages, prompts and minimized failures can carry upstream material even after names or IDs change. Move only approved, adequately attributed material into a shared regression suite. [Seed promotion guidance](../QA.md)
- **S3 and Drive.** Current Anno cache synchronization skips raw-dataset publication. Trusted jobs can read eligible existing S3 objects under the configured policy, and LitBank is expressly excluded from shared reads. A private Drive research bundle is a separate copy with its own audience. Limit any archive to material covered for the destination and preserve the source notices. Treat third-party model endpoints and reviewer exports as additional recipients.
